# Operations Kit

Copy-paste tools for running a project by hand: provider qualification questions, the standard offer format, owner status updates, and the project tracker. The process itself is in `docs/operations.md`; this file is the wording and the forms.

Rules that apply to everything below: no guarantees, no price quoted, no invented numbers, owner details private until the owner chooses. Arabic is written natively, not translated word for word.

---

## 1. Provider qualification questions

Use after the first message in `docs/operations.md`. WhatsApp or a call, under 8 minutes. Score afterwards with the 100-point table there.

### Contractors (core 8)

| # | Ask (English) | اسأل (عربي) | Listen for |
|---|---|---|---|
| 1 | Company name, CR number, who handles quotes? | اسم الشركة ورقم السجل التجاري ومن المسؤول عن عروض الأسعار؟ | CR matches; one named decision-maker |
| 2 | What work do you want more of right now? | ما نوع الأعمال التي ترغبون بالمزيد منها حالياً؟ | Clear focus, not "everything" |
| 3 | Which areas do you cover, and what project size suits you? | ما المناطق التي تغطونها وما حجم المشروع المناسب لكم؟ | Realistic range, knows their limit |
| 4 | Two recent Qatar projects: type, size, year? Photos or a reference? | مشروعان حديثان في قطر: النوع والحجم والسنة؟ هل تتوفر صور أو جهة تزكية؟ | Evidence they can show |
| 5 | Own team, subcontractors, or both? | هل تعتمدون على فريقكم أو مقاولين من الباطن أو الاثنين؟ | Honest split; who is responsible on site |
| 6 | How fast can you visit a site, and quote after the visit? | كم تحتاجون لزيارة الموقع وتقديم العرض بعد الزيارة؟ | Days, not weeks |
| 7 | How do you structure a quote: payment stages, validity, variations? | كيف تنظمون عرض السعر: الدفعات ومدة الصلاحية وأعمال التغيير؟ | Itemised, written terms |
| 8 | Usual warranty or defects period? | ما مدة الضمان أو فترة معالجة العيوب المعتادة لديكم؟ | A stated period, in writing |

### Consultants (replace 5–7 with these)

| # | Ask (English) | اسأل (عربي) |
|---|---|---|
| C1 | Which disciplines are you registered or classified for? | ما التخصصات التي أنتم مسجلون أو مصنفون فيها؟ |
| C2 | Do you handle municipality and authority approvals? Typical timeline? | هل تتولون الموافقات من البلدية والجهات المعنية؟ وكم المدة المعتادة؟ |
| C3 | Fee basis: lump sum, percentage, or hourly? What is included in each stage? | أساس الأتعاب: مبلغ مقطوع أو نسبة أو بالساعة؟ وماذا تشمل كل مرحلة؟ |
| C4 | Do you offer site supervision, and how often are visits? | هل تقدمون الإشراف على الموقع وكم مرة تتم الزيارات؟ |

### Red flags (note, score down, or reject)

- Cannot give a CR number or the name on the CR differs from who is speaking.
- Will not show any Qatar work.
- Promises a price before seeing the scope.
- Asks MimaarLink to hold money, guarantee work, or manage the contract.
- Pushes for owner contact details before the owner has chosen.

### Record per provider (one row)

Company · contact · CR · services (every one they credibly do) · areas · size range · own team / subs · warranty norm · score and grade (A/B/C/reject) · date · notes.

## 2. Standard offer format

Every provider answers the same seven items, so owners can compare. Send it to each provider with the brief. Items map to the admin bid form: **price → Price, duration → Timeline, warranty → Warranty, exclusions → Exclusions, inclusions + terms + validity + assumptions → Notes** (there is no separate inclusions field; put it first in Notes under the heading "Included:").

### Request to provider (English)

```text
Thank you for your interest. To keep offers comparable for the owner, please reply with:

1. Total price (QAR) and whether it includes VAT
2. Duration: working days from start date to handover
3. Warranty: period, and what it covers
4. Included: the main items and work covered
5. Excluded: anything not covered or priced separately
6. Payment terms (stages or percentages)
7. Offer valid until (date), and any assumptions

If you need a site visit before pricing, tell us and we will arrange it with the owner. One round of clarification is available; please reply by [date].
```

### Request to provider (Arabic)

```text
شكراً لاهتمامكم. لكي تكون العروض قابلة للمقارنة لدى صاحب المشروع، نرجو الرد على النقاط التالية:

١. السعر الإجمالي (ريال قطري) وهل يشمل ضريبة القيمة المضافة
٢. المدة: عدد أيام العمل من تاريخ البدء حتى التسليم
٣. الضمان: المدة وما يشمله
٤. المشمول: البنود الرئيسية والأعمال المشمولة
٥. المستثنى: أي بنود غير مشمولة أو تُسعَّر بشكل منفصل
٦. شروط الدفع (مراحل أو نسب)
٧. صلاحية العرض (التاريخ) وأي افتراضات

إذا كنتم تحتاجون إلى زيارة موقع قبل التسعير، أخبرونا وننسق ذلك مع المالك. تتوفر جولة واحدة للاستفسار؛ نرجو الرد قبل [التاريخ].
```

### Completeness check before entering an offer

An offer is **complete** only if all seven are present. If not, send one clarification (below), then enter what you have and mark the gap honestly ("Warranty: not stated"). Never fill a gap yourself.

| Check | Fix |
|---|---|
| Price total unclear or per-item only | Ask for one total |
| VAT not stated | Ask: with or without VAT |
| Duration is "soon" or "ASAP" | Ask for working days |
| Exclusions blank | Ask: "Please confirm nothing is excluded, or list exclusions" |
| No validity date | Ask for one |

Clarification message:

```text
Thank you for the offer. Before we share it with the owner, please confirm: [missing items]. This keeps all offers on the same basis. Reply by [date].
```
```text
شكراً على العرض. قبل مشاركته مع المالك، نرجو تأكيد: [البنود الناقصة]. هذا يضمن أن تكون جميع العروض على أساس واحد. نرجو الرد قبل [التاريخ].
```

### Normalising for the owner's comparison

- Convert everything to QAR, state VAT basis, state duration in working days.
- Copy exclusions word for word. Do not soften them.
- No "best" or "recommended" wording. Sorting stays neutral.
- Keep provider notes short; remove contact details and anything that identifies the owner.

## 3. Owner status updates

Calm, plain, one next step. Send on WhatsApp; keep the phase names the same as the project page timeline. Replace [ ] fields. Never promise a number of offers or a date you do not control.

| Stage | English | عربي |
|---|---|---|
| **A. Received** | Hello [name], we received your request for [project] in [area]. We will review it and come back to you within [one working day] with any questions. | السلام عليكم [الاسم]، وصلنا طلبكم لمشروع [المشروع] في [المنطقة]. سنراجعه ونعود إليكم خلال [يوم عمل] بأي أسئلة. |
| **B. Need information** | To prepare a clear brief we need: [1–3 items]. Photos or a short voice note are enough. Reply when ready and we continue. | لإعداد ملخص واضح للمشروع نحتاج: [١–٣ بنود]. تكفي صور أو رسالة صوتية قصيرة. أخبرونا عند الجاهزية ونتابع. |
| **C. Brief approved to share** | Your brief is ready. We would like to share it with selected providers without your name or phone number. May we proceed? | ملخص المشروع جاهز. نود مشاركته مع مزودين مختارين دون ذكر اسمكم أو رقمكم. هل توافقون؟ |
| **D. Sent to providers** | Your brief has been sent to [number] providers that fit your scope. We are now collecting their offers. We will update you by [date]. | تم إرسال ملخص مشروعكم إلى [عدد] من المزودين المناسبين لنطاق العمل. نجمع الآن عروضهم وسنوافيكم بالمستجدات بحلول [التاريخ]. |
| **E. Progress** | Update: [number] offers received so far. We are waiting for [number] more and will share them together once they are complete. | تحديث: وصلنا [عدد] عروض حتى الآن، وننتظر [عدد] إضافية وسنشاركها معاً بعد اكتمالها. |
| **F. Offers ready** | Your offers are ready to compare side by side: [link]. Each shows price, duration, warranty, inclusions and exclusions. The choice and the agreement are between you and the provider directly. | عروضكم جاهزة للمقارنة جنباً إلى جنب: [الرابط]. يعرض كل عرض السعر والمدة والضمان والمشمول والمستثنى. الاختيار والاتفاق النهائي يكون بينكم وبين المزود مباشرة. |
| **G. Fewer offers than hoped** | We received [number] offers for this scope. We can share them now, or ask a few more providers. Which do you prefer? | وصلنا [عدد] عروض لهذا النطاق. يمكننا مشاركتها الآن أو سؤال مزودين آخرين. أيهما تفضلون؟ |
| **H. Owner chose** | Thank you. We will confirm with [provider] and connect you directly. Your contact details are shared only now. | شكراً لكم. سنؤكد مع [المزود] ثم نعرّفكم ببعضكم مباشرة. تُشارك بياناتكم الآن فقط. |
| **I. Introduced** | You are now connected with [provider]: [contact]. From here the agreement is directly between you. Please tell us how it goes. | تم التعريف بينكم وبين [المزود]: [وسيلة التواصل]. من هنا يكون الاتفاق مباشرة بينكم. يسعدنا معرفة كيف سارت الأمور. |
| **J. Pause (no reply)** | We have not heard back on [project]. We are pausing it for now; send us a message any time and we will continue. | لم نتلقَّ رداً بخصوص [المشروع]. سنوقفه مؤقتاً، وعند رغبتكم راسلونا ونكمل. |

Follow-up cadence when the owner is silent: day 1, day 2, day 3 (3 attempts over 48 hours, per `docs/operations.md`), then use message J.

Never write: "guaranteed", "best price", "we recommend", "lowest", or any figure about providers or past projects that we have not verified.

## 4. Project tracker

One row per project. Keep it in a Google Sheet or Airtable for now; the admin page holds the official record. Review once at the start of the day and once at the end.

| Column | Notes |
|---|---|
| ID / date received | Admin project ID |
| Owner (first name), source | WhatsApp, referral, form |
| Project, area, size, budget range | |
| Work packages | e.g. fit-out + MEP + approvals |
| Readiness | Bid ready · Quote ready · Scoping needed · Hold |
| Stage | A–J from section 3 |
| Providers: invited / responded / offers complete | e.g. 6 / 4 / 3 |
| Next action and **due date** | One action only |
| Last owner update sent | Date |
| Minutes spent | Against the 2-hour target |
| Outcome | Chosen provider, introduced, paused, lost and why |

### Daily routine (about 20 minutes plus the work)

1. Open admin, handle new requests first (15-minute target in working hours).
2. Anything with a due date today or earlier: do it or move the date with a reason.
3. Provider chasing: at most two follow-ups each, then mark No response.
4. Every project with an owner waiting gets a status message at least every 3 working days, even if the news is "still collecting".
5. End of day: update the tracker, so tomorrow's list is already written.

### Weekly (15 minutes)

- Count only real numbers: requests, projects at each stage, offers complete, introductions. Write them as they are; never round up.
- Which stage is slowest? Which providers answer fast, which never reply? Move that into the provider scores.
- Note any messy case and how it was handled; repeated patterns become rules later.
