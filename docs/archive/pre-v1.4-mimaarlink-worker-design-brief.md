# MimaarLink Worker Design Brief

Use this brief for Fiverr designers, ad designers, social media workers, and freelancers.

## What MimaarLink Is

MimaarLink is a Qatar platform that helps project owners connect with suitable contractors and consultant offices.

Main users:

- People who need a contractor.
- Contractors who want project opportunities.
- Consultant offices that offer design, supervision, approvals, tendering, and cost review.

Main link:

- `https://mimaarlink.com/start-here`

Instagram:

- `@MimaarLink`

## Brand Style

The design must look:

- Professional
- Clean
- Trustworthy
- Qatar business style
- Modern but simple
- Not childish
- Not like a cheap handyman app

## Colors

Only use these colors:

- Navy: `#152B54`
- Dark navy: `#0D1B2A`
- Teal: `#00B59E`
- Light teal: `#D0F2EE`
- Amber: `#FFB638`
- White: `#FFFFFF`
- Soft background: `#F5F4F1`
- Muted text: `#5F6B7A`
- Border: `#E3E7EA`

Use navy and teal the most. Use amber only as a small accent, mainly for contractor content.

## Logo Rules

Use the official MimaarLink logo only.

Do not:

- Redraw it.
- Change its colors.
- Stretch it.
- Crop it badly.
- Add glow/shadow effects.
- Put it on a busy background.

## Arabic Copy Style

Use simple Arabic. Keep text short.

Good phrases:

- عندك مشروع وتحتاج مقاول؟
- انشر مشروعك
- مقاول في قطر؟
- انضم كمقاول
- مكتب استشاري؟
- انضم كمكتب استشاري
- قارن العروض قبل الاختيار
- مقاولين مناسبين
- فرص مشاريع مناسبة

Avoid saying:

- نضمن أفضل سعر
- نضمن أفضل مقاول
- مشاريع مضمونة
- جودة مضمونة
- أرخص سعر في قطر

## Meta Ads

Create ads for:

1. Project owners
   - Message: عندك مشروع؟ خلنا نوصلك بمقاولين مناسبين
   - CTA: انشر مشروعك

2. Contractors
   - Message: مقاول في قطر؟ سجّل لاستلام فرص مشاريع مناسبة
   - CTA: انضم كمقاول

3. Consultants
   - Message: مكتب استشاري؟ انضم لاستلام فرص تصميم وإشراف
   - CTA: انضم كاستشاري

Ad sizes:

- 1080 x 1080
- 1080 x 1350
- 1080 x 1920

Ad design:

- Big Arabic headline.
- Short explanation.
- Clear CTA button.
- Logo visible but not huge.
- Clean layout.
- Not too much text.

## Instagram Templates Needed

Create these templates:

- Project owner post.
- Contractor recruitment post.
- Consultant recruitment post.
- How it works carousel.
- FAQ carousel.
- Story CTA.
- Reel cover.
- Highlight covers.

Highlight names:

- ابدأ هنا
- أصحاب المشاريع
- المقاولين
- الاستشاريين
- كيف يعمل
- تواصل

## Flyer Templates Needed

Create:

- A4 flyer for project owners.
- A4 flyer for contractors.
- A4 flyer for consultants.
- WhatsApp/social version for each.

Each flyer must include:

- Logo.
- Big headline.
- 3 simple benefits.
- QR code area.
- Website or WhatsApp.
- Clear CTA.

## Final Check Before Sending

Before sending any design, check:

- Is Arabic easy to read on mobile?
- Does it use the correct colors?
- Is the logo correct?
- Is there one clear CTA?
- Is there too much text?
- Does it look professional for Qatar?
- Can someone understand it in 3 seconds?

If not, revise it.
