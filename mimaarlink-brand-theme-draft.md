# MimaarLink Brand Theme Draft

## Core Color Palette
Use this palette consistently across the website, app UI, Instagram profile, posts, stories, ads, and future pitch materials.

| Role | Hex | Usage |
|---|---:|---|
| Deep Navy | `#0D1B2A` | Main text, dark backgrounds, footer/contact sections, serious business tone |
| Teal | `#00B59E` | Primary CTA buttons, active states, trust accents, logo accent |
| Light Mint | `#D0F2EE` | Soft icon backgrounds, highlights, trust cards, subtle surfaces |
| Amber | `#FFB638` | Small attention accents, phone/contact icon, limited warning/highlight use |
| White | `#FFFFFF` | Cards, page background sections, text on dark backgrounds |

## Theme Direction
MimaarLink should feel:
- Professional
- Qatar/GCC business-ready
- Clean and mobile-first
- Trustworthy, not flashy
- Modern construction/contractor marketplace, not a handyman app

## Design Usage Notes
- Use `#0D1B2A` and `#00B59E` as the dominant brand pair.
- Use `#D0F2EE` for soft icon tiles and gentle accents.
- Use `#FFB638` sparingly for warm contrast, not as a main color.
- Keep backgrounds mostly white or very light neutral.
- Avoid too many gradients or overly colorful posts.
- Instagram content should reuse the same navy/teal/mint visual language so the brand is recognizable.

## Instagram Profile Guidance
- Profile image/logo should use navy and teal.
- Highlights can use navy backgrounds with teal icons.
- Post templates should use:
  - Navy headlines
  - Teal CTAs or dividers
  - Light mint icon containers
  - Amber only for small emphasis
- Avoid random colors that break the palette.
